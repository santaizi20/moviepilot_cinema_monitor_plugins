# 院线开票监控 CinemaTicketMonitor

当前 `0.1.0` 为基础链路验证版。

## 当前功能

- MoviePilot 第三方插件安装/加载验证
- 配置页启用/停用
- 保存配置时发送一次测试通知
- 通过 MoviePilot `post_message()` 走统一通知链
- 不在插件内保存 WxPusher Token

## 测试方法

1. 安装插件后打开配置。
2. 打开“启用插件”。
3. 打开“保存后发送一次测试通知”。
4. 保存配置。
5. 如果 WxPusher 已在 MoviePilot 中正常工作，应收到：
   `🎬 院线开票监控测试`
