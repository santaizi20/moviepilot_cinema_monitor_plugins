# 院线开票监控 CinemaTicketMonitor v0.3.0

MoviePilot V2 插件。

## v0.3.0 核心逻辑

每次扫描只请求一次影院完整排片：

```text
影院排片接口
  ↓
data.movies[]
  ↓
按电影名称匹配
  ↓
shows[].plist[]
  ↓
提取 seqNo / dt / tm / th / tp
  ↓
与上一次 seqNo 集合比较
  ↓
只通知新增场次
```

## 默认配置

- 接口：`https://apis.netstart.cn/maoyan/cinema/shows`
- 城市 ID：`10`
- 影院 ID：`25428`
- Cron：`*/30 * * * *`
- 首次仅建立基线：开启
- 新增场次通知：开启
- 场次取消通知：关闭
- 放映类型：不限

## 多电影

“监控电影”支持：

```text
奥德赛,电影A,电影B
```

也支持中文逗号、分号或换行。

同一个影院无论监控多少部电影，每轮仍然只请求一次接口。

## 放映类型过滤

- 不限
- IMAX
- 杜比
- 普通

“普通”会排除 IMAX 和杜比场次。

## 首次基线

默认开启“首次仅建立基线”。

例如第一次接口中《奥德赛》已有 37 场：

```text
第一次：保存 37 个 seqNo，不通知
下一次：发现 3 个新 seqNo，只通知新增 3 场
```

## 场次取消通知

默认关闭。

如果打开，只会对“仍未到开场时间但从接口中消失”的场次提醒，避免已正常放映结束的历史场次被误报为取消。
